# ランログ

Strava のランを自動で取り込んで、距離・ペース・心拍・シューズから成長を追いかけるアプリ。

- アプリ: https://maomax0427.github.io/runlog/
- iPhone: Safariで開いて 共有 → ホーム画面に追加

## 見られるもの

- **走力スコア（推定VO2max）** … ペースと心拍から毎回推定。5km〜フルの予想タイム
- **心拍効率** … 1拍で進む距離。「心拍150で何分/kmで走れるか」の推移
- **体力・疲労・調子** … 心拍ベースのトレーニング負荷（TRIMP）から
- **自己ベスト** … 1km / 1マイル / 5km / 10km / ハーフ / フル と更新の歴史
- **シューズ** … 靴ごとの走行距離・寿命・平均ペース
- 週・月の距離、平均ペースの推移、1kmごとのラップ

## しくみ

```
Strava ──(1時間ごと)──> Apps Script ──> スプレッドシート「ランログデータ」
                                          │
                        アプリ（このリポジトリ） <──┘
```

- `apps-script/Code.gs` … Strava の認証と取り込み。トークンはスクリプト プロパティに保存
- `metrics.js` … 指標の計算
- `app.js` … 画面
- `demo.js` … お試し用のサンプルデータ

設定手順はアプリの「設定」タブに書いてあります。
